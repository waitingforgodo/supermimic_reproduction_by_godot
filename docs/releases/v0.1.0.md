# Godot SuperMimic v0.1.0

Independent release of Godot's reference-conditioned G1 training implementation and local best results.

- LAFAN1 best: 125000 control steps, 40/40 training clips completed, mean full-clip normalized return **0.847032**.
- Six-motion specialist: 2000 new control steps, 6/6 completed, mean return **0.838217**, versus its own 0-step target-set baseline **0.754944**.
- Complete resumable checkpoints preserve every trained model and optimizer tensor. Only machine-specific metadata, project labels and data-content contracts were made portable.
- Includes independent installation, recipes, evaluation, model downloader, CPU checks and actual policy simulation GIF/MP4 demonstrations.
- README documents the world-model/BPTT architecture, RTX 5070 Laptop / Ryzen 9 8945HX hardware and measured stage durations. The **12.53-hour** LAFAN duration is only the final 20000-step continuation, not total training from scratch; specialist training took **1.06 hours**.

Download `lafan1-best.zip` and `skills-best.zip`, or run `bash g1.sh models`. `SHA256SUMS` and the repository's `models/manifest.json` verify the assets. Each bundle contains `best.pt`, `run_manifest.json`, `best.json` and `MODEL_CARD.md`.

Released best models use FP32 without EMA or AMP shaping. Optional acceleration/style experiments have bounded validation and are documented separately from headline quality results. Scores are dataset-specific training-set measurements, not hardware or held-out generalization claims.

LAFAN1 data and robot assets are not bundled. Third-party copyright, data and media notices remain applicable; see `THIRD_PARTY_NOTICES.md` in the source repository.
